Technical Blueprint v2.0

Guía de arquitectura y funcionamiento interno de la Porra Mundial 2026

🗺️ Flujo de Datos (Arquitectura)
Web / App iOS / Android (Usuario envía mensaje en el chat)
API en Render (Node.js + WebSockets)
Sistema RAG (Extrae historial del chat de MongoDB)
Groq API (La IA procesa mensaje + contexto y genera respuesta)
Web / App iOS / Android (Actualización en tiempo real)
* Todos los mensajes se guardan en MongoDB. El RAG consulta la base de datos para darle memoria a la IA.
🛠️ Componentes del Motor
Cross-Platform Apps

React Native (Expo)

Aplicaciones multiplataforma para Web, iOS y Android que ofrecen la mejor experiencia de usuario y un chat integrado fluido.

¿Por qué es clave?
  • Un solo código base para todas las plataformas.
  • Conexión por WebSockets para el chat en tiempo real.
  • Experiencia de usuario premium e inmersiva en cualquier dispositivo.
Cerebro de IA

Groq Cloud (Llama 3)

Es el hardware más rápido del mundo para ejecutar IAs. Usamos el modelo Llama 3 de 70 billones de parámetros para las respuestas del Agente Mundial.

¿Por qué es clave?
  • Genera texto a 500 palabras por segundo.
  • Permite una personalidad fluida y sin "lags".
  • Compatible con el formato de OpenAI.
NoSQL Database

MongoDB Atlas

No es una base de datos de tablas rígidas, sino de documentos JSON. Esto permite guardar datos muy distintos (predicciones, mensajes, usuarios) de forma ágil.

¿Qué guardamos aquí?
  • Usuarios y sus correos electrónicos vinculados.
  • Todas las predicciones de goles.
  • Historial de chat para contexto (RAG).
Frontend Hosting

Vercel

Es la plataforma donde "vive" la interfaz web. Mientras Render se encarga de que el bot esté vivo, Vercel se encarga de que la web sea accesible y rápida.

¿Por qué es clave?
  • Despliegue Atómico: La web se actualiza sola en segundos al guardar cambios.
  • Edge Network: Carga instantánea desde cualquier lugar del mundo.
  • HTTPS: Seguridad gestionada automáticamente.
Backend Hosting

Render.com

Aquí reside el "motor" Node.js. Provee la API REST y los WebSockets necesarios para que las apps móviles funcionen en tiempo real.

¿Por qué es clave?
  • Mantiene el servicio online 24/7.
  • Gestiona las conexiones WebSocket de los usuarios.
  • Conecta la base de datos con la IA y las apps móviles.
Memoria Semántica

Sistema RAG

RAG significa "Generación Aumentada por Recuperación". Evita que la IA "alucine" sobre lo que ha pasado en los chats de la aplicación.

¿Cómo funciona?
  • Busca mensajes pasados similares a la pregunta.
  • Se los entrega a la IA como contexto real.
  • Permite referencias como: "Como dijo Juan ayer...".
Data Source

API-Football (v3)

La fuente oficial de la FIFA. Proporciona resultados en tiempo real, goleadores, tarjetas y estadísticas de cada partido del Mundial.

¿Qué aporta?
  • Sincronización automática de resultados.
  • Validación de goleadores oficiales.
  • Mapeo de eventos (VAR, tarjetas, etc.).
🎨 Interfaz de Usuario (Frontend)
Arquitectura "Vanilla"

HTML5, CSS3 & Modern JavaScript

Proyecto construido con tecnología web pura, sin frameworks pesados. Esto garantiza una carga instantánea y una estética premium ultra-fluida.

Estética y UX
  • Glassmorphism: Efectos de cristal translúcido.
  • Variables CSS: Sistema de diseño coherente.
  • Responsive: Optimización total para móviles.
Lógica de Cliente
  • LocalStorage: Gestión de sesión local.
  • Fetch API: Sincronización asíncrona con el bot.
  • Modular JS: Código organizado y reutilizable.
🧪 Simulación y Modo de Testeo
Go-Live Simulation

Modo de Testeo Acelerado (TEST_MODE)

Para asegurar que todo funcione el día del Mundial, el sistema permite realizar simulacros completos antes del evento real.

Calendario de Mayo/Junio (Pruebas)
  • Compresión Temporal: El torneo se simula en 11 días (25 de Mayo al 5 de Junio).
  • Auto-Populate: Los resultados se inyectan solos según el calendario.
  • Simulación de Eventos: El sistema genera notificaciones push y mensajes simulados para validar el timing.
Validación Técnica
  • Integración Real: Se usa la estructura JSON oficial de la API.
  • Mapeo de IDs: Verificación de que "Equipo A" coincide con la base de datos.
  • Clean Slate: Herramientas para resetear grupos de test en un click.
🛡️ Privacidad y Seguridad

Protocolo de Datos

Para la tranquilidad de todos, el sistema sigue estas reglas de privacidad:

  • No Entrenamiento: Groq y Hugging Face NO usan nuestros mensajes para entrenar sus modelos.
  • Aislamiento por Grupo: Los datos y predicciones de un grupo jamás se mezclan con los de otro.
  • Logs Efímeros: Los logs de mensajes en los proveedores de IA se borran automáticamente tras 30 días.
  • Seguridad en Tránsito: Toda comunicación entre las apps y el backend está cifrada (SSL/TLS).
⚙️ Glosario Técnico

Node.js: El cerebro del servidor que une la base de datos, la IA y las aplicaciones móviles.

Variable de Entorno: "Secretos" (como API Keys) guardados en el servidor, fuera del código visible.

Render: La plataforma que mantiene el backend encendido y funcionando 24/7.
